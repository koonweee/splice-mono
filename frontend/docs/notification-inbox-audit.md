# Notification inbox standardization audit

September 7, 2026. Scope: the header bell, inbox overlay, notification rows,
individual actions, bulk clearing, query reconciliation, and component workbench.

| Area               | Finding                                                                                                                                                                                                    | Resolution                                                                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Overlay            | The inbox entered as a narrow right drawer and used its own full-height geometry. A viewport-wide desktop sheet made unread tint feel like a broad band.                                                   | Use the shared bottom-sheet direction, 90dvh phone coverage, a 760px height cap, safe-area padding, full phone width, and a centered 42rem desktop sheet.                            |
| Surfaces and tint  | The inbox already used semantic overlay, selected, separator, and primary-color tokens.                                                                                                                    | Preserve those tokens; add no notification-specific base colors or borders.                                                                                                          |
| Typography         | Production rows use canonical dialog, row, body, and caption roles. The workbench label still used local Mantine size and weight props.                                                                    | Move the workbench label to the canonical brand role and keep production free of local font metrics.                                                                                 |
| Actions            | Row actions were subtle, icon-only, independently labeled, and separated from row activation. The inbox had no complete-inbox action, and placing actions below metadata made each row unnecessarily tall. | Retain the row pattern, add a labeled and tooltipped icon-only Clear all action, and move row actions into a trailing column. Disable competing actions while a mutation is pending. |
| Touch and keyboard | Shared button defaults provide the compact 44px touch target contract; the row uses `InteractiveRow` and the drawer owns focus trapping/restoration.                                                       | Reuse those primitives and verify phone taps, keyboard dismissal, focus restoration, and independent secondary actions in a real browser.                                            |
| Data and errors    | Individual mutations retained failed rows, but clearing rendered rows would miss unloaded pages.                                                                                                           | Add one idempotent, user-scoped server archive operation; patch only after confirmation, retain content on failure, and refresh inbox plus summary.                                  |
| Workbench          | The inbox example covered row states but not bulk clearing.                                                                                                                                                | Add clearing and clear-error states, a fixture bulk endpoint, and tests for frame isolation and the independent transaction count.                                                   |

Exit criteria are production and workbench builds, frontend and backend type/lint
checks, targeted behavior tests, token and catalog checks, and browser inspection
across Light, Dark, and OLED at phone and desktop sizes.
